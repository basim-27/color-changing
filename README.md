# 🎨 Background Color Changer

A simple **Background Color Changer** built with **HTML, CSS, and JavaScript**.

## 🌐 Live Demo

[View Live Demo](https://basim-27.github.io/color-changing/)

## ✨ Features

* 🔴 Red background
* 🔵 Blue background
* 🟢 Green background
* 🟡 Yellow background
* 🟣 Purple background
* 🟠 Orange background
* 🟤 Brown background
* ⚫ Black background
* 🔄 Reset button
* 🎨 Text color automatically changes for better visibility

## 🛠️ Technologies Used

* HTML5
* JavaScript
